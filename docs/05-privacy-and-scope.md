# 6. Privacy and Scope (Local-First)

Raw events and OCR stay on the device; only encrypted summaries sync.

OCR is optional and per-app: captures run on-device, screenshots are deleted within 5 seconds, and an audit log shows every capture.

Typing never recorded; screenshots deleted within 5 seconds; sensitive titles masked.

Tracking, AI categorization, and nudges work with the internet unplugged.

Delete everything by date or entirely — one click, no dark patterns.

v1: Windows only. Post-launch roadmap: macOS agent, then Android collector.
