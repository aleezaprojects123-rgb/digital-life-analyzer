# Digital Life Analyzer — PRD

*Product Requirements Document (PRD) — v2.0 Market Launch Edition | October 2026*

# 4. Goals and Non-Goals

| **Version 1 goals (launch)** | **Not in version 1 (cut or deferred)** |
| --- | --- |
| Accurate timeline, no double counting | Mobile apps (post-launch roadmap) |
| The five pillars, working end-to-end | Self-experiments (cut — research feature, no launch value) |
| Local-first privacy as the brand | Ask Your Data chat (deferred to v2 — LLM chat is table stakes in 2026, not a differentiator) |
| Daily + weekly insights, score, goal tracking | Employer monitoring, keystroke recording, blocking (out of scope, trust risk) |
| Freemium launch with working Stripe payments | Task auto-detection (deferred — no paid demand signal) |

# 5. Success Measures

| **Area** | **Measure** | **Target** |
| --- | --- | --- |
| Accuracy | Correct category | ≥ 90% |
| Accuracy | Tracked time vs. real time | ≤ 5% error |
| Prediction | Precision of flagged high-risk hours | ≥ 60% |
| Prediction | Users acting on a nudge (dismiss/snooze/accept) | ≥ 30% |
| Setup | Users finishing setup in 24 hours | ≥ 60% |
| Retention | Week-4 retention | ≥ 35% |
| Engagement | Wrapped viewed weekly | ≥ 50% of active users |
| Viral | Wrapped shared to social | ≥ 5% of viewers |
| Speed | Agent CPU / memory | < 3% / 150 MB (model loaded: 250 MB cap) |
