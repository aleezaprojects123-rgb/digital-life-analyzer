# Digital Life Analyzer — Project Document

*Project Document — v2.0 Market Launch Edition | Windows (v1)*

# 3. Core Features (Foundation)

| **Feature** | **What it does** |
| --- | --- |
| Activity Tracking | Active browser tab and Windows app with exact timing; idle-aware; private windows excluded |
| Unified Timeline | Both sources merged with no overlap; gaps marked 'unknown' |
| Smart Categorization | Study, Work, Entertainment, Social Media, Other — rules first, local AI second, confidence on every label |
| OCR Assist (optional) | When a window title is unclear (games, IDEs, custom apps), on-device OCR reads the screen for a few seconds — screenshot destroyed in under 5 s, audit-logged, never uploaded |
| Analytics & Score | Daily/weekly reports, week-over-week comparison, explained 0–100 productivity score |
| Intent Alignment | How much activity supported the daily goal (semantic match) |
| Focus & Switch Tracking | Switches per hour, interruption count, deep sessions |
| Best-Hours Detection | Personal peak focus windows after 14 days, weekdays/weekends separated |
| Privacy Controls | Pause, exclude, correct, delete, export — anytime |
