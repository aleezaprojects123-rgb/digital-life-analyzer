# Digital Life Analyzer — Project Document

*Project Document — v2.0 Market Launch Edition | Windows (v1)*

# 1. Overview

Digital Life Analyzer is an AI time coach for Windows with a web dashboard. It merges browser and desktop activity into one timeline, understands what the user was doing with an on-device AI model, and — unlike every existing tracker — predicts distraction before it happens.

Market gap: RescueTime, Toggl, and ManicTime report time per app or site after the fact. We are the only tool that forecasts focus risk, acts on it, converts lost time into a recovery plan, and proves the result in a shareable weekly Wrapped — while keeping raw data on the user's device.

# 2. System Workflow

*Browser Extension + Desktop Agent → local SQLite timeline → on-device AI categorization → encrypted summaries sync to backend → forecast model trains nightly → web dashboard + desktop nudges + weekly Wrapped. Tracking and AI work fully offline.*
